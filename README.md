# AULAHUB — Web
> Sistema web para reservación de centros de cómputo dirigido a docentes de la UAS.

---

## 🇲🇽 Español

### Descripción
Plataforma web desarrollada en equipo de 5 personas que permite a los docentes de la Universidad Autónoma de Sinaloa (UAS) reservar centros de cómputo de forma sencilla. Incluye un flujo de aprobación por parte de un administrador, consulta de disponibilidad en tiempo real, historial de reservas y notificaciones de confirmación. Cuenta con una versión móvil nativa para Android (AULAHUBMOVIL).

### Tecnologías
- JavaScript
- HTML
- CSS
- Firebase (Firestore, Hosting, Cloud Functions)

### Características
- Consulta de disponibilidad de centros de cómputo
- Reservación de espacios por parte de docentes
- Flujo de aprobación por administrador
- Historial de reservas por usuario
- Notificaciones de confirmación
- Versión móvil disponible para Android

### Instalación
```bash
# 1. Clonar el repositorio
git clone https://github.com/Chiripi0rca/AULAHUB.git
cd AULAHUB

# 2. Abrir index.html en el navegador
# O desplegar en Firebase Hosting
```

## 🇺🇸 English

### Description
Web platform built by a team of 5 that allows teachers at the Universidad Autónoma de Sinaloa (UAS) to reserve computer labs. Features an admin approval workflow, real-time availability lookup, reservation history, and confirmation notifications. A native Android version is also available (AULAHUBMOVIL).

### Tech Stack
- JavaScript
- HTML
- CSS
- Firebase (Firestore, Hosting, Cloud Functions)

### Features
- Check computer lab availability
- Reserve spaces as a teacher
- Admin approval workflow
- Reservation history per user
- Confirmation notifications
- Android mobile version available

### Setup
```bash
# 1. Clone the repository
git clone https://github.com/Chiripi0rca/AULAHUB.git
cd AULAHUB

# 2. Open index.html in your browser
# Or deploy to Firebase Hosting
```
